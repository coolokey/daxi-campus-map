# 校門地標與椰林大道

依最新已發布導覽的 entrance-avenue.js、explorer.js、outdoor-world.js 與共用校園 JSON 取值。原導覽與素材唯讀。

1. 匯出有來源雜湊的 JSON：大道範圍、20 棵椰樹、步道牌與入口、銅像及司令台。
2. 室外世界向南延伸至 z=182，涵蓋 z=171 大道；不移動校門與既有建物。低卡通建築與間距保留。
3. 新增獨立地標繪圖與碰撞模組，採深度排序、可視裁切、遮擋淡出。椰樹只擋樹幹、銅像擋基座；步道名牌擋細柱。司令台為景觀平台，後側與兩側擋牆，正面可走入。
4. 校園建築目錄加入地標導航；小地圖顯示地標與大道範圍。
5. 測試三種比例的全部既有入口與大道通行、地標碰撞、導航，桌機與手機實測。備份後同網址發布，等待 Actions 並驗證正式站。
