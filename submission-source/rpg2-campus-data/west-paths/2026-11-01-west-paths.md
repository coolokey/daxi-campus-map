# 司令台、活動中心與資源回收室步道

依使用者指定正式平面圖，沿用既有草甸風格與既有道路架構。

1. 備份與 Git 分支，核對 source 模型、活動中心／回收室既有入口與司令台地標。
2. 銅像庭園南側既有步道為共用起點，向西走過活動中心北側，再分支到活動中心東門及回收室北門。另一支繞旗桿東側到司令台前方。
3. JSON 保存示意轉折；每段採同一 collision-checked findPath，一次生成。終點直接取既有入口／地標。主畫面與小地圖沿用 outdoorPaths。
4. 測試三比例的路徑連通、既有終點與逐段不穿牆。保留校舍、碰撞與原素材。桌機／手機畫面與導航驗收，審查後同網址發布。
