# 人物載入與減量隨機輪替

維持原網址 `/proposal/rpg/`。修改前版本 `b2c201d`，備份標籤 `rpg-before-character-loading-20261013`。

## 修改

- 人物模組、名冊及圖集與校園底圖平行下載，不再等 2.94 MB PNG 底圖下載完成才開始。玩家圖集優先。
- 109 張世界圖集與 109 張 512 × 640 半身像轉成無損 WebP；原 PNG、透明度、尺寸、八方向三影格與腳底錨點不變。
- 活動名冊採用 `rpg-characters-v4.json` 與 `style-v4-webp` 版本化路徑；現有瀏覽器快取可重用相同資源。
- 原桌面 6 師／6 生減為 3 師／3 生；手機原 3 師／4 生減為 1 師／2 生。固定任務角色、警衛、機器人及玩家保留。
- 每次載入先將輪替名冊副本隨機洗牌，依同一順序每 14 秒分批輪替。原搜尋名冊不重排，仍可邀請全部 91 位教師。靠近玩家的 NPC 不替換；對話時暫停輪替。
- 首批完成並開始校園畫面後，才以低優先順序預載下一小批，沒有一次下載所有人物或全部半身像。名冊延遲或重試後，輪替計時由角色實際可用時才開始。

## 量測

`verify-character-compression.py` 逐張解碼並比對所有可見 RGBA 像素（包含半透明邊緣），以及完整 alpha 通道。

| 素材 | 原下載量 | 新下載量 | 減少 |
| --- | ---: | ---: | ---: |
| 109 張世界圖集 | 10,220,425 bytes | 3,649,266 bytes | 64.29％ |
| 109 張半身像 | 18,729,046 bytes | 7,033,210 bytes | 62.45％ |
| 名冊 JSON | 98,712 bytes | 72,966 bytes | 約 26％ |

同一台電腦的 Edge 無頭模式，DPR 2、停用快取、每秒 200,000 bytes、延遲 120 ms，各量一次：

| 畫面 | 修改前首次玩家繪製 | 修改後 | 修改前地圖完成後等老師／學生 | 修改後 |
| --- | ---: | ---: | ---: | ---: |
| 桌面 1440 × 900 | 25.56 秒 | 19.47 秒 | 3.91／6.55 秒 | 0.02／0.03 秒 |
| 手機尺寸 390 × 900 | 22.92 秒 | 18.95 秒 | 3.88／3.67 秒 | 約 0.01 秒 |

這是受限網速下的單次比較，並非所有裝置／網路的保證。校園原始底圖未壓縮或改畫，仍需下載；本次主要消除地圖完成後等人物的延遲。量測記錄見 `character-loading-{baseline,optimized-reduced}.json`。

## 驗收

- 29 個測試檔、85 項測試通過；17 項角色測試包括安全 WebP、隨機副本、減量、暖載、延遲計時、邀請與標籤。
- 4 項 Node 素材檢查通過；使用逐檔 SHA 與既有匯入紀錄相符的來源快照，避免目前導覽工作區其他修改干擾驗證。
- `tsc -b`、相對路徑 Vite 建置與嚴格啟動預算通過：首次 19,993 bytes，全部 JS 898,239 bytes。
- 真實瀏覽器：3 師／3 生與手機 1 師／2 生、八方向、NPC 移動、邀請老師、玩家外觀保存、手機介面與半身像對話均通過。
- 注入名冊 503 可重試；延遲名冊 16 秒仍可移動，首批隨機角色不會立即被輪替。
- 科技館進出、上下樓與五道數學任務另外以原驗收腳本回歸。尺寸測試不等同實體 iPad Safari 驗證。
