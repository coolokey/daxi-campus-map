# 細緻六角地面與自然色階

依使用者反映修正：原半徑5.2的大地塊、僅3個相近綠色，造成大片單調。

- 半徑5.2→2.4，直徑為原46%，每格面積為原21%。人物、建物及整體世界比例不變。
- 3色→9色，增加草綠、黃綠、灰綠與淺橄欖色階；降低格線亮度及線寬。
- 稀疏草紋與米白／淡金花點，均為不碰撞的地面圖案。
- 色彩以格子索引穩定雜湊，相機平移不重抽色。
- 逆相機仿射與逆等角投影先求可見格索引，只計算鏡頭附近地塊，再做逐格裁切；避免磚變小後仍掃描整張地圖。

未修改原始校園圖、導覽網站、建築、人物、碰撞、導航及任務資料。原RPG網址維持不變。
