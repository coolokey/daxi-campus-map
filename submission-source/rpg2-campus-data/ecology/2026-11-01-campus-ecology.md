# 校園適量生態裝飾

使用者要求全校適量增加花草、蝴蝶與蜻蜓，保留校園配置、既有功能及網址。

1. 備份與 Git 分支。16 個花草群落候選區放於樹列、建築旁草地與池畔，避開通道、入口、球場與停車區。
2. 資料驅動固定種子生成，按 MapConfig 快取。以同一碰撞資料及道路／路徑／運動場保護區排除位置，不新增障礙。
3. 靜態花草快取 12 種小圖；蝴蝶只在花叢附近，蜻蜓在池上方。桌機同時可見上限 4 蝶／3 蜓，手機 2／2；尊重減少動態效果設定。
4. 可見範圍剔除、既有腳點深度排序、無外部圖片或音效載入。原人物、題目、入口與道路不修改。
5. 測試配置密度、保護區、三比例、動畫邊界與 reduced-motion；完整回歸與build。桌機／手機畫面檢查、唯讀審查、同網址發布與線上比對。
