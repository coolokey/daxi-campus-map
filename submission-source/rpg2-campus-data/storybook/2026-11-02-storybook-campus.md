# 晴日繪本校園美術統整

使用者已核准上一則設計與直接實作發布；原網址與校園導覽維持不變。

## 設計與架構
延續 Canvas 2D 等角投影與現有碰撞資料。共用材質負責全校色調、細磚鋪面、建築立面層次；迎賓路線使用既有道路範圍內的地面圖案。裝飾不增加障礙、不變更樓層、人物尺寸、任務儲存或 NPC 數量。

## 順序與驗收
- [ ] 保存來源備份及發布分支；核對最新發布 HEAD。
- [ ] 草地降低細碎紋理，統一明亮自然色系；建築增加窗框、簷下暗部、基座與屋頂細縫，維持既有遮擋範圍。
- [ ] 椰林大道與校門至前廣場改為細石磚，保留自然步道；加入低對比幾何迎賓圖案、棕櫚與人物接地陰影。
- [ ] 遠處建築標籤減量；三心保留編號與狀態文字，套用與站點相同色彩，恢復簡短階段流程。
- [ ] TypeScript、既有回歸測試、桌機／平板／手機實際畫面驗收與程式審查。
- [ ] 保存修改清單及測試報告、只打包 RPG、發布原路徑並確認正式站。

## 效能與限制
地面使用有限快取 Canvas 圖樣，建築依現有可見範圍剔除。新增內容以靜態繪製為主，不額外載入網路素材、不增加計時器。原有活動人物與生態動態繼續使用既有減少動態機制。這是美術風格化，不是實測建模。
