# 校園碰撞與程式錯誤稽核驗收

日期：2026 年 10 月 14 日。原網址： https://coolokey.github.io/daxi-campus-map/proposal/rpg/ 。備份：`rpg-before-collision-audit-20261014`。

## 已修正

1. 原地圖僅有 5 個碰撞框，其中建築範圍與彩圖不符。新增／校正為 62 個地面障礙足跡：主建築、體育館、東側樓群、連接樓、噴水池底座、旗桿底座、看台、主要花台、球場圍欄、校門柱及校園外圍。
2. 數值以原彩圖 1525 × 1031 像素定義，轉成 2400 × 1624 世界後由原 scaleMap 處理 1／1.5／2 倍，沒有改動原圖或使用 CSS 冒充碰撞。
3. 操場改從看台之間的真正樓梯開口進出，不再穿過看台；保留跑道、草地與球場開口。科技館從既有入口西側道路靠近並按 E，避免原驗收路線穿越校外或其他建築。
4. 將研究員、學生與巡邏機器人的舊出生點／路線移到可通行道路，東側巡遊道路校準為 x = 1930。返程仍保留位置與比例；舊座標若落入建築，安全移到附近通道。
5. 通用 NPC 對話下載失敗不再讓動畫與操作停住；開始任務或開啟地圖後，過期對話不會突然跳出。導師任務下載失敗恢復探索與焦點。科技館載入期間不會同時啟動快速任務。
6. 小地圖模組失敗時顯示重新整理提示，探索仍可操作。維持原 UI 樣式與觸控配置。

碰撞是原彩圖上的遊戲地面足跡，非建築實測資料。樹冠與校門上方拱梁等懸空裝飾不視為整塊牆。原 PNG 與 WebP 不改畫、不刪除，PNG SHA-256：`48e394b077e6a8729df79c20cbeb28ed55eb33dcd2a7b02e58d4dad0feabb9c4`。

## 驗收內容

- 單元檢查涵蓋所有原功能、62 個足跡代表點、三種比例出生點／NPC 及道路、球場與校門開口、真移動阻擋、舊位置恢復、樓層與題目。
- `verify-campus-collisions.cjs`：桌面 1／1.5／2 倍及手機 390 × 844，真鍵盤走到主樓與噴水池並確認不能跨越，從操場樓梯走到跑道與草地；每個 snapshot 檢查玩家與 NPC 腳底不進入障礙。
- `verify-loading-failures.cjs`：五種故障／衝突注入，包含對話下載失敗、過期回覆、導師題目載入失敗、小地圖下載失敗，以及入口載入中點快速任務。
- `verify-technology-pilot.cjs`：沿合法道路進科技館、1F／2F 樓梯、導師半身像、五題、提示／獎勵、原地返回與出口。
- 原人物名冊、91 位老師搜尋／邀請、八方向動畫、玩家外觀保存、減量隨機輪替、教師小標籤、學生無標籤、手機半身像與 503 重試均保留回歸。
- `verify-startup.mjs`：首次 JS 16,151 bytes，全部 JS 899,907 bytes，符合既有預算。
- Edge 桌面與平板／手機尺寸模擬，未聲稱實體 iPad Safari 驗證。紅框畫面僅是驗收疊圖，正式遊戲不顯示。

## 主要修改檔案

`src/game/data/maps/campus-obstacles.ts`、`campus.ts`、`src/game/data/residents.ts`、`src/presentation/{main,character-world,pilot-controls}.ts`，碰撞／巡邏／返程測試與驗收 scripts。

完整原始碼在 `submission-source/rpg-source.zip`；完整修改清單在同資料夾 `pilot-changed-files.json`。修正前後測試與瀏覽器驗收 JSON 另存同資料夾。教師／學生無損 WebP、桌面 3 師 3 生與手機 1 師 2 生的減量隨機輪替沿用上一階段，不增加多人在線宣稱。

最終本機結果：30 個測試檔、93 項單元測試，以及 4 項 Node 素材檢查全部通過；所有瀏覽器回歸報告的 page errors 與資源失敗為零。故障注入案例的預期失敗資源另列於 loading-failures-local-check.json，無未捕捉例外。
