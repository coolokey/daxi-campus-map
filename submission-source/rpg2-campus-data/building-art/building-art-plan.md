# 校舍辨識與立面優化

已核准方向：保留校園位置及原網址，以行政大樓、科技館、活動中心為重點，將共用樓層立面套用全校。

1. 核對導覽 campus-data.js 的 hasPitchedRoof、explorer.js 活動中心太陽能板，保存來源備份與 Git 分支。
2. 用獨立建築美術資料保存屋頂種類。斜屋頂增加屋脊；平屋頂增加女兒牆與細部；活動中心保留大型屋頂與太陽能板特色。
3. 立面依 sourceHeight 還原實際樓層數，增加樓板、凹入窗帶與柱列。入口只使用現有 portal trigger 製作地面門檻及方向提示，不製作虛假入口或新增通行障礙。
4. 將屋頂與面牆分別判斷遮擋並淡化，保持其他面牆可見；更新屋頂剔除範圍。
5. 執行幾何／碰撞／入口／渲染測試、桌機與手機視覺檢查、程式審查；打包、原網址發布及正式站驗收。

採程序化 Canvas 繪製，不新增人物圖片、外部材質或定時器。造型是依既有資料風格化，不宣稱實測還原。
