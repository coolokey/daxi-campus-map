# 柔和草甸校園美術升級

使用者提供11張低多邊形草原RPG參考圖，明確要求將現有校園改為該方向。保留Canvas等角投影、校園資料、樓層、控制、題庫、人物與原網址。目標是實際遊戲2.5D視覺升級，不宣稱已改成WebGL真3D。

1. 備份ZIP與Git分支。核對rpg-quiz-battle-game，僅採素材重用／角色分層原則，本輪不新增答題戰鬥。
2. 預設外觀改為連續草甸，移除六角色塊。快取草地、自然小花與細石紋理；沿原有道路／入口做暖砂石鋪面，校門街道、籃球場與跑道保留。
3. 原樹位改為快取多面樹冠、分枝、落地陰影與玩家遮擋淡化；從導覽補入9個既有景觀樹候選，過濾建築內位置，樹幹碰撞與render共用同一清單。
4. 訓平池增加漸層、漣漪、蓮葉、岸邊草與既有屏障上的卵石；裝飾不移動池址。校舍增加柔和光影、弱化粗框，保留棟色與占地。
5. 介面改奶油白＋森林綠，縮減遮擋，保留三心階段提示與觸控區域。角色及老師半身像沿用現有素材。
6. 單元測試樹位碰撞／遮擋／可達，完整回歸與build。桌機、iPad、手機、樓層與任務實測，審查後同網址發布並驗證線上檔案／畫面。
