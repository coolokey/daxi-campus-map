# 自然草甸道路修正與空拍參考紀錄

## 問題與改動

前版草甸只替換入口窄步道的材質，椰林大道、校門橫向道路與生態步道入口仍獨立繪製灰色硬邊路面。此次三個繪製檔共用自然鋪面，預設不再顯示灰色車道與中心虛線。

路面包含暖土深淺漸層、固定世界座標的碎石紋理、朝原多邊形內側微變的草緣、不規則邊線與柔邊陰影。建築周邊鋪面移除預設矩形框與彩色邊帶。保留木藝對照的灰路與石磚。

所有變更限制在繪製層，未修改校園模型、地圖碰撞、道路連通、建築占地、入口、樓層、導航與正式平面圖。草緣碎石屬小型裝飾，不新增碰撞。道路寬窄變化以視覺邊緣表現，不是重新規劃校園道路。

## 效能與驗證

土色紋理只建立一次。畫面外鋪面先以實際 Canvas 投影 bounds 剔除，再生成草緣，避免遠端鋪面每幀處理。沒有新增外部素材載入。

- TypeScript、正式 Vite build 通過。
- 完整回歸：49 個測試檔案、162 項通過。
- 桌機：校門場景無灰色主道路、沿導航抵達科技館入口並進入 1F。
- 390×844 瀏覽器手機尺寸：室外人物、道路、三心提示、操作鍵及小地圖可見；非實體手機測試。
- 木藝模式切換正常，仍保留原路面。
- 本機瀏覽器未觀察到 error／warn。公開部署與檔案比對另存 output/natural-roads-qa/published-verification.json。
- 唯讀審查：繪製順序、clip 狀態、可見範圍剔除、內側法線及零長邊防護未發現 P1／P2。
