# 大溪國中校園導覽

以大溪國中 115 學年度校園平面圖製作的第一階段互動校園導覽。

## 功能

- 互動 2D 校園平面圖與場所標記
- 校園外部簡化 3D 導覽
- 建築、入口與運動場地搜尋
- 點選場所顯示資訊卡
- 以 `?to=<id>` 直接開啟場所，例如 `/?to=admin`
- 2D 與 3D 共用 `src/data/campus-data.json`

## 本機執行

```bash
npm install
npm run dev
```

測試與建置：

```bash
npm test
npm run build
```

## 後續第二階段

依同一份場所資料增加建築樓層、室內走廊、樓梯與教室節點，再將導航路徑延伸到室內。
