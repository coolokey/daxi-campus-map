# 景觀碰撞修正

銅像石柱與底階、庭園灌木、樹幹、旗桿、排球柱、籃球架立柱、花台及長椅改為實體障礙物。碰撞從可見模型的世界矩陣產生，與鍵盤、手機搖桿、導航共用同一份資料。

景觀實體建立提前至空間索引及導航圖之前；行政立面的碰撞登記也統一到這個時序，避免晚加入的障礙物未被索引收錄。移動繼續沿用原有每段 0.18 的判定，樹冠、地面標線與遠景山丘不阻擋地面行走。

原中庭花台與 907 教室入口重疊，現將花台縮窄並移至中庭兩側。長椅沿東側縱向擺放，留出可容納人物及導航網格的中央通道；中央通廊觀賞點移離樹幹。銅像原 z=32 觀賞點保留。

驗證資料：

- `qa/landmark-spatial-verification.json`：109 個目的地皆可達，導航路段、樓梯與教室入口無失敗，11 條跨校舍實際移動函式路線通過。
- `tests/landmark-collision.test.ts`：銅像四向、斜向、高速與跳躍碰撞，景觀實體抽查，銅像後方繞行及地面通行。
- `scripts/verify-landmark-release.cjs`：獨立與嵌入版桌機鍵盤、手機搖桿、銅像繞行、景觀碰撞與截圖；結果分別保存到 `qa/landmark-collision-local` 及 `qa/landmark-collision-published`。

本次為已確認景觀缺漏及相關導航修復，不宣稱已逐件認證全校所有裝飾模型。
