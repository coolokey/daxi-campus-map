# 行政主入口與校門側小側門修正

依 S__66011287.jpg、S__66011292.jpg、主入口／造景近照與多角度空拍，將行政大樓主立面改為面向銅像廣場。原來錯誤的 +Z 主門設定同時影響建築、造景及導航；本次改用入口段與內段共同的局部座標，門廊、屋頂、牆面、碰撞及導航一起轉正。

主入口朝 -X，入口段長立面沿 Z；孔雀位於操場側（低 Z）花圃，魔術方塊位於校門側（高 Z）花圃。S__66011292.jpg 的一樓校門側短牆新增低矮深色斜雨遮及小側門，2F／3F 為封閉短側牆。舊庭園東側兩株示意樹與照片造景重疊，已移除；西側庭園樹與兩株照片花圃樹保留。

保留全部既有房間 ID、樓層及行政連棟關係；側門後的窄通道為導覽示意接法，沒有宣稱由照片證明室內配置。側通道後端已封牆，不新增未確認後門。前後段以照片比例配置，後段與九年級棟留出 1.5 示意單位間隙；所有尺寸不是實測公尺。

獨立審查已通過：主門／側門共同基底、後排與連接屋頂坡向、持續碰撞、未確認後門封閉、樹幹與魔術方塊分離。最終測試、畫面與部署證據存於 qa/admin-entrance-2026-10-17/pre-release-verification.json。
