# 步行操作驗證

此階段承接已授權的自動導航接管與手機雙搖桿。只更新 daxi-campus-map；既有校園空間及其他 GitHub 專案不變。

## 行為

手動鍵盤、方向按鈕、拖曳轉頭與搖桿有效輸入會暫停帶路，保留目的地。繼續帶路從人物實際位置重算路線。第一人稱帶路保持第一人稱，取消舊鳥瞰 tween；切換鳥瞰、視窗失焦、頁面隱藏、開啟設定／平面圖／說明／照片／教室面板均停止移動。各輸入來源分開保存，放開方向按鈕不影響仍按住的鍵盤。

手機左搖桿依人物方向前後／側移，右搖桿轉頭與抬低視線。兩個 Pointer ID 獨立，取消／失去 capture／放開即清除。死區 12%，最大向量長度 1，輕推採比例速度。沿用相同防穿牆、樓梯與地面高度；桌機原鍵盤／方向按鈕仍可用。
