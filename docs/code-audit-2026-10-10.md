# 網頁程式檢查與修正（2026-10-10）

## 修正項目

- 導航終點標記改為基準高度加上週期位移，避免每幀累加漂移；使用既有時鐘時間，避免再次讀取時鐘造成下一幀時間差失真。
- 相機牆面查詢使用空間索引，維持原本的邊界判定。
- 教室名稱貼圖依名稱與分類快取鍵更新，只重建實際變更的貼圖，並補上 sRGB 編碼。
- 煙火音效以使用者意圖及請求序號管理非同步啟動，關閉或快速切換後不會被過期的 resume 請求重新開啟。
- 共用開發版與正式版載入提示；較慢時提供重試及平面圖，WebGL 啟動失敗時顯示可操作的替代畫面。
- 舊版檢視器不再因父元件重新渲染而重建場景；移動依時間計算，輸入欄不觸發行走，失焦清除按鍵，卸載時釋放共用 GPU 資源一次。
- 靜態景觀依相同材質、陰影及顯示群組合併幾何；保留貼圖、房間識別與碰撞相關物件，以及樓層群組。
- 背景分頁跳過主要繪製工作。

## 實際驗證

同一鳥瞰起始場景，合併前繪製呼叫 1,408 次，合併後 771 次，三角形數量皆為 166,160。這是繪製量的比較，不代表固定的載入秒數改善。

瀏覽器確認首頁、手冊入口及二樓展示，二樓完整清單列出 34 間空間。正式建置完成。新增回歸測試涵蓋載入復原、音效競態、標記位移、碰撞索引、貼圖差異更新、場景生命週期及靜態合併。

完整結果：36 個測試檔、133 項測試全部通過。驗證指令為 `node node_modules/vitest/vitest.mjs run --pool=threads --maxWorkers=1 --testTimeout=30000 --hookTimeout=30000`；本機記憶體吃緊，因此限制同時執行的工作數。正式入口與場景 HTML 所引用的 5 個本機資源皆存在。

## 限制

舊版檢視器仍有超過 500 kB 的獨立 JavaScript 分塊警示，只在指定 legacy 檢視器時載入；預設 HTML 入口不載入它。模型中的「名稱待確認」仍保留，需以校方確認資料補充，不推測替換。
