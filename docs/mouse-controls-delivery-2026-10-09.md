# 滑鼠操作分析與套用

參考：https://3dtypsmap.vercel.app/ 。本次重新下載公開 HTML，比對本機先前分析的公開程式，內容相同。參考其操作概念，以本專案人物、碰撞及鏡頭系統重新實作。

| 功能 | 大勇公開程式 | 大溪實作 |
| --- | --- | --- |
| 鳥瞰旋轉 | 左鍵拖曳 | 固定左鍵旋轉，與步行設定分開 |
| 鳥瞰平移 | 右鍵／Shift＋左鍵 | 沿用 OrbitControls 相同手勢 |
| 鳥瞰縮放 | 滾輪 | 沿用鳥瞰縮放界限 |
| 步行拖曳 | 左鍵按住轉頭 | 左鍵、右鍵兩種設定；捕捉游標與放開清理 |
| 懸停轉頭 | 移動滑鼠；點擊／Esc 暫停 | 同樣操作，滑出場景停止，點擊繼續 |
| 邊緣持續轉向 | 依場景寬度、靈敏度曲線 | 6% 邊緣區，限制 40～96 px，二次曲線 |
| 游標鎖定 | 點擊鎖定；Esc 解除 | 新模式；不支援／被拒絕時保留左鍵拖曳 |
| 平滑轉頭 | 時間補償指數平滑 | 相同概念；水平、垂直靈敏度與反轉設定 |
| 跟隨距離 | 第三人稱滾輪，1.8～9 | 同範圍，第一人稱不改眼睛位置，避牆及避階梯 |
| 偏好與快捷鍵 | 記住模式、速度、靈敏度、反轉；[／] | 本機儲存偏好；[／] 以 5% 調整靈敏度 |
| 操作中斷 | 彈窗、失焦、鎖定解除清理 | 設定、搜尋、教室卡、失焦、取消拖曳清理 |

搜尋、樓層、教室卡等既有滑鼠點擊介面繼續使用。本次公開程式檢查未找到場景 Raycaster／雙擊事件，因此沒有把點地瞬移、雙擊縮放當成參考網站功能。

## 驗證

全套 27 個測試檔、100 項測試通過；npm run build 通過；共用空間驗證 108 個導覽目的地、92 個實體空間及 7 條跨樓層／平台路徑均通過。

- 新增 10 項滑鼠測試：邊緣、滾輪單位／界限、平滑、拖曳釋放、觸控隔離、懸停暫停、彈窗、偏好、鎖定啟動／異常位移／Esc、階梯鏡頭。
- 程式審查發現高仰角遠距鏡頭進入階梯，已改為 44 點路徑採樣，與共用地面、樓梯及牆體比對。審查原重現位置修正後保留約 0.214 的地面間距。
- 桌機瀏覽器確認實際拖曳、滾輪跟隨距離、懸停 Esc 暫停、模式切換。內建瀏覽器拒絕游標鎖定，已確認顯示左鍵拖曳備援；真正鎖定的生命週期以事件測試驗證。
- 觸控保留原手機操作系統，mouse-only Pointer Events 不處理 touch。

發布僅更新 coolokey/daxi-campus-map，維持既有網址。
