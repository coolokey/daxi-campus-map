# 網站檢查、修正與煙火升級紀錄

日期：2026-10-16。基準版本：`9ddcc710f4ff0a07f668e0c627a99c46b5d08782`。

## 檢查範圍

檢查現用 3D 校園的入口、導覽、人物互動、碰撞與路徑、桌面／手機介面、煙火與音效，以及提案頁的嵌入與發布流程。保留的舊版 React 入口檢查主要操作與版本識別；預建 RPG 檢查資源可達性和跨頁訊息邊界，未宣稱逐行稽核其壓縮引擎。這次沒有變動已校正的行政大樓、科技館等校舍幾何。

## 已重現並修正的 10 項錯誤

P2 表示影響正常操作、聲音或發布一致性；P3 表示較低影響的健全性／效能問題。

| 項目 | 等級 | 原本問題 | 修正及證據 |
| --- | --- | --- | --- |
| 1．手機煙火聲過弱 | P2 | 觀賞鏡頭較遠，距離衰減使遠爆有效增益約 0.026，低於氣氛聲 0.12；低通也削弱爆裂感。 | 觀賞距離保留適度音量、降低氣氛聲、調整濾波與壓縮，加入近爆、低頻聲體及尾韻分層。真實錄音離線混音比較見下文。 |
| 2．密集煙火漏掉爆裂聲 | P2 | 18 個聲源被尾音等占滿時，新的主要爆裂會直接捨棄。 | 主要起音具有最高優先權，較低優先權聲源以短淡出退役；活躍池 18、退役池最多 4。獨立複核先填滿 18 個遠爆，再播放 40 個近爆，近爆遺失 0 次；停止後雙池均清空。 |
| 3．按鈕的空白鍵被人物跳躍攔截 | P2 | 按鈕取得焦點後，Space 觸發跳躍並阻止原生按鈕操作。 | 按鈕、連結等控制項保留原生 Space／Enter；WASD 移動仍可使用。已加入回歸測試。 |
| 4．右鍵轉頭誤開教師名冊 | P2 | 在教師上短按右鍵，也被當作人物點擊。 | 僅主指標左鍵開啟人物資料，右鍵保留相機操作。測試同時驗證左鍵仍正常。 |
| 5．嵌入版本可能沿用舊樣式／程式 | P2 | 同步流程對部分已存在的 HTML 引用檔只補缺檔，不更新舊副本。 | 每次同步均覆寫被引用的 JS／CSS；隔離檔案系統測試確認既存檔也更新。 |
| 6．提案頁切換建築目的地無反應 | P2 | 校園已載入後，跨頁導航只辨識教室，忽略建築。 | URL 與提案訊息共用目的地解析，支援建築與教室並保留舊行政大樓連結相容性；來源驗證保留。 |
| 7．嵌套入口預載舊包 | P3 | `/proposal/campus/` 外殼預載歷史 bundle，產生多餘下載。 | 建置時依目前版本重產外殼，使用正確嵌入 bundle 與共用資源路徑。已加入建置回歸測試。 |
| 8．特殊目的地字串解析錯誤 | P3 | `__proto__`、`constructor` 等繼承屬性被誤當別名。未重現程式執行或原型污染。 | 使用自身屬性檢查，公開導航入口拒絕非法型別／未知目的地；非法輸入不會中止原本有效路線。 |
| 9．舊版人物漫遊按鈕切換兩次 | P2 | 同一次點擊重複發出模式事件，結果回到原模式。 | 移除重複事件，實際 React 元件測試確認一次點擊僅一次切換。舊版另標示模型年代與正式版連結。 |

| 10．舊版陰影使用已移除模式 | P3 | 舊版初始化使用 PCFSoftShadowMap，當前 Three.js 會警告並自動改用 PCFShadowMap。 | 直接使用當前支援的 PCFShadowMap，保留既有實際渲染行為並消除警告。 |

## 美術、人物與煙火

保留男／女生、制服／便服、教師輪替、警衛與人物對話。人物點擊與鍵盤焦點問題已修正。空間驗證包含 109 個目的地、92 間實體房間及 11 條人物移動路線，未發現無法到達目的地、阻塞圖邊、門口或樓梯驗證失敗。這些檢查不能代表所有自由操作姿態都經過窮舉。

煙火增加雙色內外花球、彗星形狀、短暫爆心光暈與保留歷史位置的金色拖尾。先保留完整花球主點，再依畫質分配尾跡；維持各畫質粒子總量上限，避免尾跡擠掉整朵花球。手機鏡頭由 800 調至 600，兩側裝飾煙火限制在可見範圍。保留兩行「80週年／大溪國中 生日快樂」、降低動畫、停止還原與預設音效開啟／音量 100%。

以瀏覽器 `OfflineAudioContext`、實際 18 個錄音樣本、相同 14 次爆裂時程做 11 秒比較：

| 指標 | 原版 | 修正版 |
| --- | --- | --- |
| 輸出 RMS | 0.01654 | 0.03397 |
| RMS 分貝 | -35.63 dB | -29.38 dB |
| 波形峰值 | 0.11885 | 0.50352 |
| 超過數位滿幅的樣本 | 0 | 0 |
| 主要爆裂起音 | 14 | 14 |

此比較提升約 6.25 dB，並保留爆裂瞬態；未發現本段渲染削波。這是固定時程混音量測，並非所有手機喇叭、音量或完整表演的聽感保證。實際輸出留存於 `qa/site-audit-2026-10-16/fireworks-improved.wav`。

## 安全性結果與限制

| 檢查 | 結果 |
| --- | --- |
| npm 已知漏洞 | 本次查詢 131 個依賴，已知漏洞 0；另外查詢內嵌 `three@0.128.0`，未返回 advisory。 |
| DOM／XSS 注入 | 將含事件處理器的 HTML 放入教室名稱／搜尋資料，實際處理器將它顯示為文字，注入圖片元素為 0。 |
| localStorage 原型污染 | 用 JSON 特殊鍵測試實際解析器，未知鍵被移除，`Object.prototype` 未被修改。 |
| 跨頁訊息偽造 | 保留 origin 與 source 雙重檢查；外站及錯誤視窗無法觸發目的地導航。 |
| 公開憑證格式 | 490 個追蹤文字檔及提交用原始碼 ZIP，常見 API 金鑰／私鑰格式未匹配；ZIP 未發現 `.env`／私鑰／憑證檔名。未掃描完整 Git 歷史，格式掃描無法證明不存在任何敏感內容。 |
| 發布資源 | HTML 引用未缺檔；現用 RPG 入口可達的 10 個 JS 模組均存在。 |
| HTTPS 與政策標頭 | 正式主站／提案頁為 HTTPS 並提供 HSTS；未提供 CSP、Referrer-Policy、Permissions-Policy 回應標頭。這屬於可加強項，這次未重現由此造成的攻擊。 |

仍建議後續在可控制回應標頭的託管層加入經測試的政策。現有 inline boot 與 onclick 必須先遷移或設定正確雜湊，直接套用嚴格 CSP 會破壞現有功能，因此這次沒有盲目啟用。套件 advisory 查詢、字串注入與格式掃描均有範圍限制，不能據此宣稱網站完全安全。

舊版 React 模型仍屬早期模型，未在這次重建為近期照片版本；已加上清楚提示與正式版連結。建置仍提示舊版單一 chunk 約 556 kB，可在另次專項工作拆分；現用 3D 入口不會預載這個舊版 chunk。
