# 首次載入效能檢查與修正

基準版本：7657274。使用相同程式、jsdom 幾何／碰撞／導航初始化，Canvas／WebGL 繪圖以驗證用 stub 取代。以下 CPU 計時不代表使用者實際網頁總載入時間，未含網路與 GPU；裝置及網路仍會影響首次載入。

| 全部受測場景腳本 CPU | 3694 ms | 1398 ms |

主要原因與修正：

1. 新版原本先載入 React 入口及含 Google 字型的舊版 CSS，才建立 iframe。改為原生 DOM 小入口，React 與舊版 CSS 僅在 viewer=legacy 時載入。既有 2D／舊版 3D 入口、to／view 深連結保留。
2. 靜態路網建置多次以同起點重跑 BFS、碰撞與地面查詢。以 layout、高度、stage 模式及起點隔離並共用搜尋前沿，路網建置完成立即釋放。人物出發點的執行期導航使用新搜尋，避免舊狀態影響結果。
3. 外部腳本逐一阻塞 HTML 解析。統一 defer，使下載能並行，執行仍依原順序。
4. 字型 CSS 原本阻塞，改為非阻塞載入；平面圖、空拍照片與手繪美術圖在隱藏面板中原本立即下載，改為開啟面板或點擊連結時才載入。
5. 正式 build 將校園 iframe 的 27 個 classic script 與 8 份樣式合併成各 1 個快取檔，首頁直接建立導覽 iframe；首屏遮罩在第一個完整 WebGL frame 後收到 `campus-ready` 訊號才淡出，等待場景建置時仍立即顯示可辨識的校園入口。

驗證：28 個測試檔、105 項測試及建置通過。完整空間驗證保持 108 個目的地、92 個實體空間、17455 個路網節點；不可達、阻擋邊、樓梯與入口錯誤皆為零。正式 build 由 27 個 script／8 份樣式合併為 1 個 script／1 份樣式；瀏覽器啟動量測由 39 個請求降至 2 個主要資源請求，並確認首頁、舊版入口及 901 教室深連結（3F 與導航目的地）正常。獨立唯讀審查未發現 P1／P2。
