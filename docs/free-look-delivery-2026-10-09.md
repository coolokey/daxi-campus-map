# 自由視線與人物朝向修正

重新讀取大勇公開 HTML，與本機先前分析的公開程式相同。其 l0 使用 y.yaw 控制視線與行走，第三人稱 y.face 在靜止時保持不變，移動時才轉向；H0 分別更新鏡頭與人物朝向。因此第三人稱可以繞到人物正面。

大溪原本在滑鼠轉頭及每幀步行更新時直接將 avatarGroup.rotation.y 設為 avatarAngle，造成鏡頭繞行時人物也轉身，總是看到背面。現在 avatarAngle 保留為視線方向，人物實際朝向由 rotation.y 保持。滑鼠或手機轉頭只改視線；A／D 主動轉向；移動時人物面向移動向量；自動帶路保持既有朝向更新。第一人稱原地環看不改人物位置，第三人稱可以看到人物正面，切換視角保持原有視線。

新增整合測試涵蓋兩種視角轉頭後執行動畫更新仍保持人物位置與朝向，以及自由看景後開始走路的方向。全部 27 個測試檔、102 項測試及 npm run build 通過。瀏覽器確認第三人稱由背面繞到正面、第一人稱原地環看，小地圖仍為正門廣場・1F。
