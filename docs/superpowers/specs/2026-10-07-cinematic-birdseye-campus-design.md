# 大溪國中全螢幕鳥瞰導覽設計

## 目標

將目前的頁面式展示改為全螢幕 3D 校園導覽系統。預設使用電影式鳥瞰全校，讓來賓先辨識操場、主要校舍、植栽與山景；操作介面則提供搜尋、快速目的地、樓層、迷你地圖與人物漫遊入口。

## 視覺與鏡頭

- 首次載入以 8 至 10 秒的空拍下降鏡頭進場，然後停在可旋轉與縮放的校園鳥瞰。
- 校園模型使用現有平面圖、空拍構圖與校園照片校準；校舍要有屋頂、樓層、窗格、入口、材質和陰影，不採用單色積木外觀。
- 操場、球場、道路、樹列及背景丘陵共同構成校園環境；實景照片只用於資訊卡與必要的視覺輔助，不把照片偽裝成可行走建模。

## 介面

- 頂部：校名、搜尋欄、人物漫遊、總平面圖、操作說明。
- 快速目的地列：行政處室、主要教室、圖書館、體育館、操場等。資料不足的目的地不呈現虛構資訊。
- 右側：全校與 1F 至 4F 樓層按鈕。尚未建有室內模型時，樓層按鈕以不可用或明確的「規劃中」狀態呈現。
- 左下：依平面圖校準的迷你地圖與目前鏡頭／Avatar 位置。
- 右下：行動裝置可用的移動控制；桌機保留鍵盤與滑鼠。

## 互動

- 點選建築後開啟實景照片資訊卡，提供「鳥瞰定位」、「開始導覽」、「建築介紹」。
- 使用者主動點選「人物漫遊」才進入第三人稱 Avatar；鳥瞰是預設且可隨時返回。
- 搜尋結果、快速目的地、迷你地圖標記與 3D 校園位置都從同一份校園資料讀取。

## 非目標與限制

- 本階段僅處理校園外部、主要建築入口和鳥瞰導覽；室內走廊、教室與跨樓層路徑另行製作。
- 尚未由照片確認的建築外觀會採一致的推定樣式，並保留在 `MAP_ISSUES.md` 供後續校正。

## 驗收

1. 進站即為可操作的全螢幕校園鳥瞰，而非長頁面內容。
2. 可使用搜尋或快速目的地將鏡頭聚焦到對應建築。
3. 可開啟總平面圖、迷你地圖與建築實景資訊卡。
4. 第三人稱模式可從明確入口啟動並返回鳥瞰。
5. `npm test` 與 `npm run build` 均通過，並在 GitHub Pages 實際確認。
