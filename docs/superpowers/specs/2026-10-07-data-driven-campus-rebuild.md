# 依校園圖資重建 3D 導覽規格

## 目標

將目前少量建築的簡化 3D 場景，改為以官方 115 學年度校園平面圖為空間依據的完整鳥瞰校園。使用者進入後先看見可操作的全校鳥瞰，再以搜尋、快速目的地、建築資訊卡與人物漫遊進行探索。

## 可借鏡的參考資料

參考資料夾 `F:\1151005---創意教學 - 複製\daxi-3d-campus` 的 `campus.json`、`rooms.json` 與 `navigation-graph.json` 提供已整理的校園座標、建築尺寸、樓層、入口與路網概念。本專案只會以其作為資料校對與功能架構參考，不複製其 `index.html` 程式碼、CSS 或任何視覺資產。

## 場景

- 依平面圖放置正門大道、行政前後棟、活動中心、操場、司令台、戶外球場、八／九年級教學棟、科技館、綜合大樓、藝術館、七年級新大樓與東側通廊。
- 每棟建築由資料驅動：位置、寬深高、樓層數、屋頂型式、入口與樓層高度。
- 大溪國中既有實景照片只用於校舍外觀顏色、窗格、屋頂與資訊卡比對；未經照片確認的細節採一致的中性樣式並記錄在 `MAP_ISSUES.md`。
- 以操場、道路、樹列、球場、丘陵背景與日照陰影建立可辨識的校園環境。

## 互動

- 預設全螢幕鳥瞰，可旋轉、縮放與聚焦指定建築。
- 搜尋、快速目的地、資訊卡與迷你地圖必須共用同一份校園資料。
- 人物漫遊只由使用者啟動；外部導覽完成後才逐步加入室內樓層、路網與自動帶路。

## 驗收

1. 3D 場景包含完整主要建築群，位置關係與校園平面圖一致。
2. 鳥瞰畫面能辨識操場、活動中心、行政棟、三排教學棟與東側專科建築群。
3. 既有照片能在確認對應的建築資訊卡顯示。
4. 測試、正式建置與 GitHub Pages 實際畫面皆通過檢查。
