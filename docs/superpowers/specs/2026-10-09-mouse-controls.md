# 滑鼠完整操作

使用者指定分析大勇並直接套用，依本輪重新讀取的同版公開程式實作。步行保留左／右鍵拖曳並加入移動轉頭、點擊鎖定游標；游標邊緣持續轉向，滑鼠輸入指數平滑，Esc 暫停或解除鎖定，鎖定失敗可繼續拖曳。拖曳採 pointer capture，放開／取消／失焦清除；觸控仍交由既有手機模組。

鳥瞰固定左旋轉、右及 Shift 左平移、中鍵與滾輪縮放，與步行轉頭選項分離。第三人稱滾輪變更 1.8～9 的跟隨距離，同樣通過既有遮牆鏡頭；第一人稱滾輪不變更人物位置。教室／樓層／搜尋／小地圖點選延續現有行為，不加入參考網站沒有的畫布點地瞬移或雙擊功能。

轉頭靈敏度、反向、速度與模式記在此瀏覽器，新增操作提示及 [／] 靈敏度快捷鍵。面板、彈窗、失焦、模式切換均解除滑鼠捕捉並停止殘留轉頭；輸入框與 UI 捲動不觸發畫布操作。人物移動與鏡頭仍保持共用前進方向。測試手勢生命週期、hover 暫停、邊緣速度、zoom limits、偏好復原、設定與 bird 分離，以及全部既有測試／空間路徑。僅部署現有大溪專案。
