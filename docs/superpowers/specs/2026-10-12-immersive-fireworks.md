# 八十週年沉浸式煙火整合分析與設計

使用者已指定直接分析後實作完整系統，沿用既有發佈網址。主入口為 Vite；現行導覽為傳統 script 的 Three.js r128 WebGL 場景，iframe 承載。人物、碰撞、樓層及鏡頭共用 explorer.js 的 animate。另有 public/proposal 雙介面展示，校園為複製的靜態頁，RPG 為獨立的原生 Canvas 地圖與 React 題目。現有音效為本機合成，並非錄音。

方案比較：Fireworks.js 與 Canvas 2D 能快速製作平面特效，但獨立 Canvas 無法自然使用校舍深度遮蔽或立體光照。採現有 Three.js 的 Points／ShaderMaterial，共用 WebGL 深度緩衝與渲染迴圈，不新增攔截觸控的 Canvas。

模組：anniversary-model.js 管理 30 秒編排、粒子形狀、效能層級與文字點位；firework-scene.js 管理火箭、真 3D 爆裂、尾焰、煙霧、文字粒子及環境光；firework-audio.js 載入 assets/sounds/manifest.json 所記錄的真實錄音，管理聲源、位置、距離延遲、混音與回響；anniversary-fireworks.js 只負責非模態 UI、狀態及場景生命週期。

流程：0–3 秒倒數；3–5 秒夜間轉場；5–12 秒零星；12–22 秒密集含菊花、球狀、垂柳、扇形與連發；22–25 秒粒子匯聚 80；25–28 秒祝福；28–30 秒漸弱並恢復白天。按停止立即恢復光線與清掉所有臨時節點；可重播。觀賞視角可選，人物行走與既有介面始終保留。

聲音：主動按開始時可啟用音效，另有靜音與音量。真實檔案只在需要時載入，逐項顯示載入結果；失敗顯示缺失，絕不以合成聲冒充。每類至少三個不同錄音或不同原始片段；原檔、裁切範圍、處理、授權及雜湊保存。用 StereoPanner、低通、距離衰減、聲速延遲、卷積環境回響、並發上限、壓縮與保守輸出增益避免疊加破音。背景及展示分頁隱藏時暫停並取消未響的聲音。

任務：提供同源自訂事件及 API，可設定 requireQuest／questId；本次接上展示 RPG 的能源核心任務完成通知，完成後出現校慶獎勵入口，仍由使用者點擊開始。不得由題目觀察器猜測成功。

品質：桌面／iPad／手機自動分級，低 FPS 只降不升，提供降低特效與減少動態模式；低動畫保留平緩 80 點位與祝福。測試涵蓋時間邊界、物理／數字、聲音載入失敗與競態、真實 decode／source.start／離線混音峰值、場景遮蔽、行走、觸控、重播、關閉清理、展示切換及子路徑資源 404。
