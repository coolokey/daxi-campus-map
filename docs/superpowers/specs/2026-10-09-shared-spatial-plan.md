# 校園共用空間配置

使用者已同意依 2026-10-08 的建議進行，先完成空間一致性階段。原網址及目的地 ID 保留，只修改 daxi-campus-map。

## 設計

以 115 平面圖的固定空間代碼、樓層與順序作為資料依據。圖中的直欄樓層必須分別讀取，不把橫列當樓層；照片檔名不視為證據。照片可確認外觀與流通結構，未有測量資料的尺度仍為示意比例。

新增共用空間模型，提供每層 room / stair / wc / passage / void 格子、局部矩形、世界矩形、門口、走廊及梯段。房間幾何、碰撞、樓梯、導航、編輯格子及小地圖消費同一模型。依圖中可確認的房間順序與廁所／穿堂補齊配置。固定目的地 ID 作為相容連結；新增 spaceCode 為圖中房間編號，與年度名稱獨立。

室內牆與樓板、門縫、梯井開口及導航同源；各座樓梯可上下通行。綜合／科技等非直線配置採多區塊，不能把停車場或通廊畫成教室。無依據的電梯、地下室不新增。小地圖按人物實際樓層繪製，年度名稱或配色更新時清除快取。

## 驗證

逐棟比對平面圖樓層與代碼；測試所有房間在模型中唯一出現，門口位於可通行邊界、各樓梯連續上下、導航路段不穿牆。瀏覽器檢查編輯面板寬度與間隔、樓層小地圖、改名後配色同步、桌機及手機。完整 npm test 與 npm run build，審查後只推送既有 GitHub 專案並驗證原站點。
