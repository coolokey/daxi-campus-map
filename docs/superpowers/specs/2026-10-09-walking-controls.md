# 步行接管與手機雙搖桿

承接已同意的後續操作階段，保留共用空間與原 GitHub Pages。此階段不需要 Google 帳號、雲端或更改校園模型。

按 W／S／A／D、方向鍵、手機方向鍵、操縱搖桿或拖曳轉頭時，立即停止自動帶路。保留目的地及路線，按「繼續帶路」重新從人物目前位置算路，不把人拉回原起點。第一人稱啟動帶路仍保持第一人稱；切成鳥瞰或視窗失焦停止移動。搜尋框與配置面板打字不觸發步行。

手機步行時顯示左移動、右轉頭雙搖桿；左側前後與側移皆依人物方向，斜向速度不超過直走，右側以時間推進轉向及上下視線。沿用移動速度與轉頭倍率，以及同一碰撞／樓梯地面函式。Pointer ID 分別管理兩指，pointerup／cancel／lostcapture、視窗 blur、頁面隱藏、開啟對話框或切換模式均清除輸入與搖桿外觀。

控制採既有深綠與米白，左右明確標「移動」「轉頭」，人物／路線保留在中間；小地圖保留左下區域並上移避開搖桿，速度與轉頭設定在最下方。桌機原方向鍵保留；手機短橫向視窗縮小控制、以緊湊導航卡避免遮擋。保留鍵盤替代，不引入假登入按鈕。

驗證：先失敗測試，再驗證接管、目前位置重算、第一人稱保持、輸入框例外、雙指獨立、觸控取消、失焦與模式清除、斜向限速。真實 jsdom 場景驗證與瀏覽器拖曳／鍵盤實測；57 項原測試全部保留；發布到同一專案。
