# 大溪 80 校慶煙火彩蛋

使用者已確認：點蛋糕 → 校園入夜 → 約 20 秒煙火秀 → 點亮 80 → 自由放煙火；補充需要音效。

整合至目前主要入口 `public/campus-explorer/index.html`。以原生 dialog 承載透明 Canvas，底下保留真正的立體校園，開啟時暫停行走、切換觀景鏡頭及夜色，關閉恢復原視角與光線。入口採小型蛋糕圖示與生日提示。

煙火含升空尾跡、圓形、星形、愛心爆裂；終場以金色光點排列 80 並顯示校慶祝福。結束後可點擊天空或使用鍵盤按鈕發射。提供重播、返回、Esc 關閉、焦點返回、手機排版與減少動態模式。

音效預設關閉，使用者點擊音效按鈕後才建立 Web Audio。以合成噪音與振盪器生成升空、爆裂與和弦，限制音量及並發數；關閉、背景分頁暫停音效與動畫，恢復時不補播。無外部媒體服務。

驗證：時間軸及形狀模型單元測試、原有測試、正式建置、Playwright 桌面與手機開啟／音效／終場／自由發射／重播／Esc／恢復／減少動態／背景暫停檢查及截圖。不自動發布。
