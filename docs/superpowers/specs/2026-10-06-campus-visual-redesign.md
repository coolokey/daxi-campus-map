# 大溪國中寫實化 3D 校園導覽視覺重製規格

## 目標

將目前的概念原型重製為可辨識、可探索、以實際校園資料為依據的 3D 校園導覽網站。視覺品質以「寫實化中面數」為基準，接近參考網站的清楚導覽、鳥瞰與場所定位體驗，但使用大溪國中自有平面圖、空拍影片、校園照片、模型與程式碼。

## 圖資使用與優先順序

1. 校園總平面圖：校園邊界、建築相對位置、道路、操場、校門與戶外場所。
2. 空拍影片：建築朝向、量體比例、屋頂、校舍群、操場與周圍山坡林相。
3. 校園照片：立面、窗格、入口、植栽、地坪、通廊與開場／資訊卡實景素材。
4. 影像生成素材：僅用於補齊未拍攝的角度、低細節背景和風格一致的環境資產；不得複製參考網站的任何模型、圖片或美術素材。

若圖資互相衝突，新增 `MAP_ISSUES.md`，標註來源、位置、疑點與 `NEEDS_CONFIRMATION`，不自行判定。

## 視覺系統

- 校舍：白灰外牆、真實窗格節奏、深色或紅色屋頂、入口柱列與合理樓高。
- 環境：紅褐與灰色道路、操場跑道、草地、山坡林相、喬灌木與校園樹列。
- 光線：晴天自然光、柔和陰影、明確天空與遠景層次。
- 導覽介面：深色半透明 HUD、黃金色導覽焦點、簡潔中文標籤；不遮擋校園。
- 資訊卡：使用對應實景照片、建築名稱、類別、樓層與「前往／查看地圖」操作。

## 首頁與開場

1. 以校園實景照片與空拍視角建立開場畫面。
2. 開場依序點出校門、操場、主要建築與校園環境。
3. 使用者可跳過開場，直接進入 3D 導覽。
4. 開場完成後，鏡頭降至入口附近，顯示第三人稱導覽 Avatar。

## 3D 場景第一階段

- 重新建立校園殼層：操場、球場、主要道路、校門、學生生活動中心、行政與教學建築、通廊、停車區。
- 各建築使用資料驅動的 `id`、位置、旋轉、尺寸、樓數、入口與對應照片。
- 建築模型與搜尋／導航資料分離；禁止由 Mesh 名稱推斷地點。
- 建築立面採可重用模組：牆面、窗格、屋頂、入口、柱列與植栽群。
- 遠距使用簡化量體，接近時載入窗格、屋頂與入口細節。

## 操作與角色

- 預設第三人稱 Avatar；第一人稱為可切換模式。
- Avatar 目標身高約 1.7m，具備站立、行走、跑步與跳躍狀態。
- 桌面：W A S D 移動、滑鼠轉向、Shift 跑步、Space 跳躍、V 視角切換、M 地圖。
- 手機：虛擬搖桿、視角拖曳、地圖與互動按鈕。

## 品質與驗證

- 每一棟已建模建築都要可對應至少一張實景照片或空拍可見證據。
- 開場、鳥瞰、第三人稱與第一人稱畫面都要進行視覺檢查。
- 重要建築在 2D 平面圖與 3D 場景的位置一致。
- 桌面和手機各完成至少一次操作驗證。
- 原始照片不修改，網站使用副本或經授權的衍生素材。
