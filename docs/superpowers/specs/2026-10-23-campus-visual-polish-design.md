# 大溪校園視覺與探索介面改善

使用者已於 2026-10-23 指示依上一輪提出的優先順序實作，並提供四張門塔與警衛室照片。沿用現有深綠／米白手冊視覺、Three.js 與來源同步架構，延續既有修改後發布授權。

## 設計與順序

1. 一般探索 UI：手冊預設收起；桌面將搜尋及步行／鳥瞰作為主要控制，樓層維持易達，穿著、編輯及師生功能收進可展開工具。手機保留單一工具入口，避免兩張面板共開。所有既有功能、搜尋入口、導航卡及 gatePreview 均保留。
2. 材質：使用本機程式生成可重用材質，改善行政區鋪面與入口及門塔／警衛室表面。避免遠端貼圖依賴，不移動行政區房間或花圃。
3. 校外道路與遠景：基於現有椰林通道與校園邊界補強路緣、鋪面和景深，採低細節環境層；沒有地圖證據時不新增虛構實名街廓、商家或建築。校門中央通行軸維持暢通。
4. 照片修正：四張原始截圖僅供參考，不覆蓋原檔或直接作為可見材質（包含地圖游標／浮水印）。確認白色方形門塔、頂端金球、藍黃曲線、外側校名／內側題字、紅色雙坡屋頂、米白牆與淺藍牆腳、警衛室窗／門／LED牌。比例為照片估計，並非測量。保留共用入口座標及可走通道；無法由照片辨認的小字不自行補造。

## 架構與驗證

- 修改 public/campus-explorer 來源，沿用 scripts/sync-anniversary.cjs 同步 proposal；不改產生的 hashed 資產。
- 保留房間固定 ID、使用者自訂名稱、導航與師生資料；新增可視立面時確認碰撞與門塔開口一致。
- 行為變更先加狀態回歸測試；材質及場景需真實 renderer 畫面驗證，幾何改動另驗 motor 與導航。
- 驗證桌面、320／390／430 直向及 844×390 橫向，正式與嵌入、探索／鳥瞰樓層／導航／煙火模式；保留相片對照及畫面證據。
- 原隔離 worktree fbb6f59 為目前 main；既有 QA 未追蹤檔保留。實作完成後審查、建置、推送 main、等待對應 SHA Actions 並驗公開版本。

## 決策

沿用既有介面作局部調整優於重寫，能保留校門找處室與已修好的花圃導航。照片修正置於最後階段，避免在 UI 與道路檢查前同時改動空間。現有比較方向與使用者執行指示已構成設計同意，不重複要求批准。
