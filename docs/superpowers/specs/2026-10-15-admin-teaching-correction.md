# 行政／教學大樓圈選照片修正

使用者提供「1151015空拍圖/行政大樓修正說明.jpg」圈選行政前棟，要求修改行政與教學樓，沿用既有發布授權。

已確認：行政前棟是紅／米黃坡頂獨立矩形三層樓；後方桃米屋頂是另一辦公棟，前後由中央窄橋相接。目前西端U連廊位置不符。南橫教學棟與東側縱教學棟實際形成連續L形，模型有8示意單位斷口。九年級中央縱翼在平面圖較短，現與東縱翼等長不符。

實作：行政前棟標示為行政大樓、後棟依既有學務與總務職能區分名稱，不交換房間ID。行政門面改為石材窗間柱與封閉窗帶，主屋頂改紅前坡／米黃後坡及四坡收邊。中央行政連橋僅2/3樓連前棟既有穿堂，保留1F辦公室既有配置與入口，不讓橋穿牆。教學東縱翼延至南橫棟，兩棟共享走廊邊界開口及同樓層路線。九年級棟適度縮短，但保留全部房間及樓梯淨空。尺度依照片與平面圖比例，非測量。

驗證：先新增中央橋與L形接點／地面支撐回歸測試；共用幾何、碰撞及導航驗證全部目的地、樓梯與房間門口。電腦／手機實際走訪，獨立程式碼審查，同步嵌入版、build、整合遠端新提交、發布原網址並驗證。
