# 科技館朝校內車道入口修正

使用者確認：結合空拍與門口近照，以面向校內馬路為入口方向。
照片來源：使用者提供的科技館門口資料夾內 4 張照片，只作建模參考，不公開包含人物的原圖。

- 原因：科技館沿用通用的一樓開放走廊，導航入口卻放在長軸兩端，未表現面向車道的玻璃門。
- 在 L 型內凹、長翼靠車道的西面建立主要入口；相對位置按空拍與近照推估，未經現場測量。
- 共用空間模型記錄入口、三級臺階、平臺與室內銜接；模型、碰撞、地面高度、導航使用同一資料。
- 補鋁框玻璃、上方亮窗、右側扶手及磁磚紋理；封閉原本誤作入口的走廊兩端。
- 保留教室名稱、樓層、L 型輪廓、樓梯、屋頂與綠棚。
- 驗證：先觀察入口回歸測試失敗，再修正；實體步行、全路線稽核、樓層、主頁與內嵌版桌機／手機檢查。
- 完成後發布既有 GitHub Pages，依 commit 確認 Actions 及線上資產內容。
