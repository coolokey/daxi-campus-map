# 警衛室旁行人小門修正計畫

目標：依使用者照片與現場功能說明，區分學生步行小門與汽機車寬門，沿用既有版本與發布網址。

架構：在共用 entrance 計畫新增 pedestrian 的內外與門檻位置，所有步行起點使用同一來源。警衛室左側留出連續穿廊，既有白門仍為警衛室房門；小門另建開門狀態金屬格柵。以實體碰撞與導航馬達驗證。

1. 先加入失敗測試：小門座標、穿廊行走、校門起點到行政處室必經小門、車道仍可通行。
2. 校正主屋左側牆線、窗戶與小門；同步碰撞範圍，避免在警衛室牆上畫假門。
3. 共用步行起點與圖形節點改小門；入校路線先經小門內側，再接既有路網。校外椰林目的地維持校外。
4. 示意人物避開小門通行區。文字首頁與第一步標明步行由警衛室旁小門進出。
5. 聚焦測試、完整導航稽核、正式與提案副本同步建置、獨立審查。
6. 精確加入本次來源與證據，提交並發布原路徑，依發布版本核對公開模型與手機帶路。

驗收：小門位於門塔與值勤窗之間，連通校外與校內；學生路線不再預設穿寬車道；警衛室房門位置保留；尺寸為照片推估。
