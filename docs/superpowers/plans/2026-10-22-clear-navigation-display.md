# 家長訪客帶路畫面改善

延續已確認「家長到校門口，用手機找處室」方向及本次「接續改善」授權，完成後發布原網址。沿用 field-guide 與現有 Three.js 導覽，不修改建築、碰撞或路線。

## 實作範圍

- 導航就緒、行走、暫停、受阻、抵達時，以同一個狀態 class 管理畫面；取消或關閉抵達資訊後恢復原探索工具。
- 次要工具預設收起，保留可展開的「工具」。桌面導航期間將工具與煙火入口放到上方，導航卡位於其下，消除浮動入口覆蓋。
- 人物穿著在導航時收起；需要時可由工具重新開啟。手機以釋放後的空間調整搖桿，不遮擋導航按鈕。
- 導航卡突出目前階段，完整階段可展開閱讀；保留暫停／繼續、取消、目的地筆記與抵達資訊。
- 只在步行模式精簡浮動教室標籤：採用 canonical 房間節點、人物目前樓層、鄰近距離，目的地優先並避免標籤／工具遮擋。鳥瞰完整樓層展示與清單維持原行為。

## 檔案與驗證

- field-guide.js、field-guide.css、mobile-layout.css：狀態、工具與導航資訊。
- navigation-guide-model.js、explorer.js：步行標籤的純選擇模型及場景整合。
- tests/field-guide.test.ts、tests/navigation-guide-model.test.ts：先測失敗，再實作；保留預覽與鳥瞰回歸。
- 對正式與 proposal 副本同步建置，驗證 320／390／430 直向、844×390 橫向與桌面；檢查導航與工具、煙火入口、搖桿邊界及 console。
- 導航幾何不變，不重跑無關的完整碰撞稽核。實際走訪學務處及跨樓層處室，確認 UI 變更不干擾移動與抵達。
- 獨立審查並修正後，推送、等待對應 SHA 的 Pages 成功，再檢查公開版本。
