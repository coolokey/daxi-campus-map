# 行政主入口與側門朝向修正計畫

使用者已核對主入口朝銅像，以及 S__66011292.jpg 的一樓校門側小側門，並授權修改後發布。

## 架構
行政 root、入口段及內段共用 orientation=statue 的 world/local：world(u,v)=(b.x-v,b.z+u)，u 沿 Z，v 朝銅像。前段中心(-21,28.5)，實體寬10深26；內段中心(-9.5,28.5)，寬8深24，避免侵入九年級棟。尺寸為照片比例示意。原處室ID及樓層維持不變。
