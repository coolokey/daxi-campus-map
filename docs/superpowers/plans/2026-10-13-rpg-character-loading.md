# RPG 人物載入效能實作計畫

目標：保留既有 Q 版造型、八方向動畫、教師標籤、學生無標籤與半身像，縮短老師學生的載入等待。網址維持 /proposal/rpg/。

原因：main.ts 把角色模組下載放在 2.94 MB 地圖 PNG 的 onload 之後；角色 JSON 約 99 KB，單圖集約 80–100 KB，下一批 NPC 在輪替當下才開始下載。

設計：原 PNG 留存，另建立無損 WebP 與版本化 v4 輕量 JSON；角色模組與地圖平行下載，地圖尚未就緒時略過繪製。優先玩家與當批 NPC，當批圖集完成後暖載下一批，不一次下載 109 位。半身像保留 512×640 並採無損 WebP，仍按對話需求下載。版本化 URL 使用現有瀏覽器快取，不增加 Service Worker。
