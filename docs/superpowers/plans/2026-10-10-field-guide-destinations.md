# 探索手冊目的地資訊與手機操作

**Goal:** 接續已確認的探索手冊設計，收合手冊後仍能操作帶路，並顯示可核對的目的地資訊。

**Architecture:** 保留既有導覽 HUD 與事件處理器，將 HUD 移至獨立的目的地卡。導覽引擎在成功規劃後更新目的地 ID；手冊依 ID 讀取既有房間資料，照片僅用已核對的行政前棟與操場素材，附來源年代。

**Tech Stack:** 原生 JavaScript、CSS、Three.js、Vitest、jsdom。

- [x] 導覽成功時發布 HUD 的目的地 ID，失敗時保留原導覽狀態。
- [x] 目的地卡獨立於側欄，選取目的地後手機收合側欄；帶路與取消按鈕仍可使用。
- [x] 可展開目的地筆記：建築、樓層、固定編號與適用照片；未知房間不產生臆測內容。
- [x] 狹窄與橫向螢幕保留搖桿操作區，目的地卡內部可捲動。
- [x] 測試側欄收合、取消導航、切換目的地與深層連結；完成建置與瀏覽器驗證。
- [x] 僅提交本次檔案，發布原 GitHub Pages，核對公開版本。
