# 行政二樓共用辦公入口及連續樓梯校正

**Goal:** 依照片與口述修正後發布：總務、人事、會計共用入口；進門左側總務、右前會計、右後人事。樓梯在總務旁、油印室對面，同一樓梯井連通 1F–3F。油印室與教務處同側，校長室在教務處對側。

**Architecture:** 延用共用幾何。總務在學務上方、人事會計在會客與教練室上方。以開放辦公分區及一個外牆入口表達辦公區，不虛構三組外門。保留相容 ID，各區路線經共用入口後以碰撞網格找路。

**Files:** spatial-plan-data.js：用途與相容 ID；spatial-plan.js：連續梯井、房間及入口；spatial-world.js：共用辦公外牆、門牌、導航；minimap.js：共用外門；admin-shared-entry.test.ts、admin-ground-scheme-c.test.ts、outdoor-world.test.ts：配置、碰撞及全程路線；verify-admin-second-floor.cjs：本機及發布後實際自動帶路。

1. 新增需求測試，確認先失敗；更新前版已被使用者否決的配置斷言。
2. 將已確認一樓梯位連續到三樓，保留一樓房間及原進出動線，調整三樓與新梯井相交的示意房間邊界。
3. 建立共用辦公入口、三個開放分區，對齊樓下用途；依照片校正校長、教務、油印關係。
4. 經共用入口以室內網格路線抵達各區；驗證完整路段及階梯，不能只判斷圖上可達。
5. 完整測試、建置、桌面／手機自動帶路，審查後提交原 main，等候版本對應 Pages 成功。
6. 正式與提案線上驗收，保存版本及證據。

## 實際帶路追加校正

瀏覽器驗收確認校門口示意人物會擋住固定路線，重啟仍走原路。新增限同樓層的局部避人路線：等待 0.6 秒後尋找 8 公尺內重接點，搜尋限 12 公尺範圍；不跨樓梯或穿牆，無可行路仍保留安全暫停。測試涵蓋固定人物阻擋、逐段碰撞，以及實際 animate 行走迴圈抵達；線上驗收保留人物與原碰撞設定。
