# 單一行政大樓與科技館輪廓修正計畫

**Goal:** 依使用者 PDF 圈選與 11 張空拍修正單一行政主體、科技館寬主體與窄長翼、藝術館窄高比例，發布原網址。
**Architecture:** campus-data.js 管理建築身分與尺寸；spatial-plan.js 共用樓板、房間、走廊、樓梯及路徑；spatial-world.js 生成可見體塊與碰撞；photo-roofs.js 生成對應屋頂。保留內部 ID 與目的地，後方短棟按處室用途標示，不虛構正式棟名。尺寸為照片比例示意。

- [x] 科技館綠色窗帶及圓弧突出部分，屋頂與碰撞同步。
