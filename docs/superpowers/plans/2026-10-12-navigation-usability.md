# 校園導覽第一輪改善

依本次對照分析及使用者「請進行改善」的授權，在既有手冊風格與路徑引擎上完成四項改善。

- [x] 搜尋入口略過舊歡迎說明；搜尋、步行／鳥瞰與樓層固定顯示，原有控制只保留一份。
- [x] 導航引擎發布明確的待出發、帶路、暫停、受阻、抵達及取消事件。只有走完實際路徑才顯示抵達。
- [x] 根據本次實際路徑的高度變化呈現階段；不虛構電梯、無障礙動線或測量距離。
- [x] 帶路時收合手冊；抵達後保留名稱、棟別、樓層、編號與既有實景資料，提供關閉及繼續搜尋。
- [x] 先加入行為測試確認失敗，再實作；驗證接管／取消／換目的地／深層連結及完整測試、建置。
- [x] 同步報名展示站副本；實際檢查桌面、手機與上樓抵達流程，保存新證據，不覆寫既有 QA。

檔案：`public/campus-explorer/field-guide.js`、`field-guide.css` 負責介面；新增 `navigation-guide-model.js` 負責純路徑階段計算；`explorer.js` 發布路徑狀態；`index.html` 保持載入順序；`scripts/sync-anniversary.cjs` 同步嵌入版；相關測試位於 `tests/`。

驗收：搜尋不重複歡迎卡；收合手冊仍可搜尋、切換模式及樓層；帶路／暫停／受阻不誤報抵達；抵達資訊不因 HUD 隱藏消失；換目的地或取消清掉舊資訊；控制不遮蔽手機搖桿；樓層標籤與 RPG 整合保留。
