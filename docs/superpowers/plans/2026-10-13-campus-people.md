# 校園師生實作計畫

**Goal:** 在現有導覽加入示意學生與可查詢的教職員，保留人物與導航操作。

**Architecture:** 從圓潤角色建立獨立人物實例；名冊只公開姓名、現任職稱及已核對照片。照片取自姓名標示明確的教職員頁，未匹配者顯示待補。教務主任張致信、總務主任張智鈞依使用者確認。校園配置為導覽示意，不能稱為人員即時位置。

**Tech Stack:** Three.js r128、原生 JavaScript、Vitest/JSDOM、Python/Pillow。

- [x] 核對並裁切具名照片；建立完整名冊與本機來源登錄，排除學生及家長會照片。
- [x] 角色工廠獨立材質、四肢與髮型，保留玩家外觀與導航狀態。
- [x] 場景加入 12 位示意學生與有照片的老師；手機限制同時更新人數，遠處隱藏。
- [x] 右側「校園師生」入口提供搜尋、名冊、照片卡與處室帶路；點選場景人物開啟介紹。
- [x] 測試獨立人物、正確名冊、拖曳不誤觸、碰撞與對話暫停；同步提案版、建置。
- [x] 程式審查、桌機／手機目視驗證、原網址部署及公開驗證已完成。部署版本 9c098e7，工作流程 38327100266 成功。

Ruling: 先前人物群像與點選老師設計已獲「請繼續執行」授權，沿用現有介面配色。未確認照片不套用相似人像。角色為程式繪製的外觀特徵示意，介紹卡呈現核對後照片。
