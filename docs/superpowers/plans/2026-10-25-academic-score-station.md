Reuse office furniture coordinates and preserve the door-to-center aisle. Add a deterministic dwell controller: accumulate 3000 ms only in walking mode, correct floor and near station; movement, background tab and suspended UI reset progress. One automatic attempt per visit, reset after leaving the area. Request a separate window with window.open popup features. Browser popup blocking is outside application control; when blocked, show an explicit user-click link/button that opens the same URL. Never pre-open blank windows or replace the campus tab.

Validate controller timing/reset/re-entry, popup success/blocking/failure, station geometry and physical aisle/routes. Build and synchronize both existing entrypoints, then verify the release and live desktop/mobile behavior without submitting student credentials.
