# 複製資料夾分析與改善交付

## 程式比較

| 程式 | 架構 | 本次用途 |
|---|---|---|
| 複製版 `daxi-3d-campus` | 單頁 Three.js r128，程序模型、樓梯碰撞、樓層群組、導航節點與 A* 搜尋 | 沿用場景與互動程式，拆分配置／渲染／美術檔 |
| 複製版 `future-campus-rpg` | React＋Canvas 2D，房間地圖、角色控制、挑戰、NPC、收集任務與學習摘要 | 分析結構，保留其題庫與遊戲程式 |
| 現版 `daxi-campus-map` | React＋Three.js，簡化盒狀模型，場地資料與建築模型座標分離 | 保留舊頁，入口改為移植改善版 |
| 複製版 `3D` 與校園照片 | 空拍、校門、立面、走廊、室內與運動設施照片 | 以實際畫面判讀材質，不能僅依檔名推定建築 |

## 具體改善

- 以移植版座標統一建築、房間與導航，不再混用舊模型座標。
- 行政前後棟前後排列，八、九年級縱向棟及中庭，東側藝術館→科技館→綜合大樓的順序。
- 九年級 908／905／903 位於 1F，907／904／902 位於 2F，906／901 位於 3F；804 回到 1F。
- 修正藝術館導航高度及活動中心樓梯高度，使其符合共同樓板高度。
- 修正斜屋頂擠出起點與縱向屋脊，切層時隱藏上方屋頂及屋頂設施。
- 本地化渲染函式庫，保留來源與授權。
- 增加磁磚、鋪磚、中庭綠籬與座椅、後側擋土牆及樹叢，調整色彩、光影與霧。
- 增加預設導覽視角、暖陽切換與實景對照，手機中庭採較高視角。
- 限制近景室名為選取建築的當前樓層，桌面最多 8 個、手機最多 4 個。
- 保留舊版對照與目的地連結相容；沒有更動複製資料夾原始檔。

## 美術協作

已呼叫 GPT-6 Astra 分析原始平面圖、實景照片、程式與完成截圖，兩輪審查促成座標／屋頂／標籤／鏡頭修正。另以 imagegen 產生 `public/campus-explorer/campus-illustration.png`，作為獨立手繪概念美術圖，非測量地圖。
