# 室內樓梯與走廊照片改善

## 現有架構與分階段方案

現有 spatial-plan 與 walk-world-math 共用樓梯坡道、轉折平台與門口資料；spatial-world 產生模型及碰撞；explorer 統一樓層顯示。這次保留平面配置及碰撞支撐，改善視覺構造，避免重寫已驗證的動線。

1. 重新檢視原始照片：行政大樓 38、41、47；活動中心 4、12、18；走廊穿堂影像；校園照片 S__66011290。校園照片資料夾主要是外觀與操場，室內細節以 3D 資料夾為主要證據。
2. 補齊實心梯級、踏階前緣、金屬立桿與轉折平台護欄；活動中心補磁磚分縫及藍色階梯側緣，行政樓梯補網狀防護細節。照片中的行政扶手同時有不鏽鋼與深色部分，不一律套用木色。
3. 走廊補米灰天花、橫梁、長型日光燈、灰色踢腳線及地面分格。天花必須在步行模式可見、樓層鳥瞰剖面模式隱藏，且不跨越樓梯開口。
4. 回歸驗證樓梯升降、導航及樓層剖面，建置、同步內嵌版、發布後檢查電腦與手機畫面。

新增細節以共用材質與合批幾何為主；不公開原照片中的人像、公告或個人資訊。所有尺寸為現有導覽模型的示意比例，沒有以照片聲稱實測尺寸或臆造未拍攝的室內格局。

## 實作與檢查結果

- 原本每級為薄板，現在補實心踢面；踏階前緣定位於每級前端，保留原平滑支撐坡道以維持穩定上下樓。
- 活動中心加入藍色階梯側漆、磁磚縱向分縫、止滑線、平台磁磚及木色扶手／金屬立桿；行政樓梯採灰色階面、不鏽鋼色扶手及網狀防護示意。
- 走廊加入灰色踢腳線、雙向地坪分格、米灰天花橫梁與長型日光燈。天花、橫梁與燈具排除樓梯洞口，室內可見、樓層鳥瞰剖面隱藏。
- 審查發現天花只在改樓層時更新，切換視角沒有同步；已改成樓層與視角變更都呼叫共用更新，並補回歸測試。
- 完整測試 42 檔／197 項通過；共用真實場景引擎檢查 109 個目的地、92 間實體空間、17,313 個導航節點，未發現不可達目的地、阻擋路徑邊、錯誤樓梯或門口失敗；7 條代表性行走路徑正常。
- 本機瀏覽器實際走訪行政樓二樓走廊、下樓前往活動中心二樓，再往返三樓看台。走廊的橫梁、燈具、分格與踢腳線可見；未記錄 JavaScript error。
