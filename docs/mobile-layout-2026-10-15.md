# 手機控制項重疊修正

範圍：校園導覽的手機直向與橫向配置；沿用現有導覽與人物設定。

- 上方固定排列手冊、煙火與工具，觸控按鈕至少 44 px 高。
- 直向面板與底部搖桿、人物設定分區；短橫向面板置於兩側搖桿之間，內容可捲動。
- 手冊和工具互相收合；轉向或進入小螢幕時關閉展開面板。
- 搜尋結果在工具內依序排列；教室卡開啟時暫時收起樓層清單。
- 速度、轉頭與煙火設定使用相同面板界線，避免遮住底部操作。
- 小地圖避開人物設定；可點選樓層標籤避開新增頂部控制項。

驗證：320×568、390×844、430×932、568×320、844×390、915×412；涵蓋步行、工具、手冊、搜尋、導航、教室清單與卡片、煙火及設定面板。已實際操作短橫向面板底部選項，並量測可見控制區的矩形重疊與超出視窗情況。這是瀏覽器尺寸模擬，未宣稱已在所有實體手機驗證。
