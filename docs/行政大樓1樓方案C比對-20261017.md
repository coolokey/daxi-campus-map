## 定位與資料原則

- 主入口持續朝蔣公銅像；不因圖面上、下方向而再次旋轉整棟。
- 本圖用於一樓房間與通行關係；二、三樓用途不依此圖改名或移層。
- 圖中一樓會客室應採獨立目的地，不直接覆蓋現行二樓校長室旁空間。
- 保留孔雀、魔術方塊、行政大樓外觀及既有發布網址。
- 沒有實測尺寸，先沿用現有建築尺度作比例配置，清楚保留示意性質。

## 已確認的入口

1. B：會客室與教練室各有通往右側走道的獨立門，不經另一間房間。
2. E：一樓先由中央通廊繞至樓梯左側進入梯前平台，再接既有梯段；保留既有樓板洞口與上層落點。

## 執行順序

1. 確認上述門位與樓梯入口，建立一樓共用配置與房間識別碼相容表。
2. 在 `spatial-plan-data.js`／`spatial-plan.js` 修正房間、廁所、穿堂與東向通廊；由共用模型產生實體牆門、碰撞、小地圖及導航。
3. 檢查現有 `photo-facade.js` 的側門與封牆是否符合新通道，避免畫面有門但實際被牆擋住。
4. 檢查正門至各辦公室、東向出口及樓梯的實際行走；完成電腦、手機及嵌入版驗證後，循原路徑發布。
