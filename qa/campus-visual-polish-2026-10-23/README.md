# 校園 UI／材質／道路／照片校門驗證

依 2026-10-23 使用者授權順序完成：一般探索 UI、校門與行政材質、校外道路遠景，最後四張照片校門修正。

## 已完成

- 桌面手冊預設收合，搜尋／步行／鳥瞰／樓層保持直接可達；次要控制移入工具抽屜。所有原按鈕只搬移，不複製 ID 或改寫儲存值。
- 手機一般探索、導航、工具、手冊及校慶入口仍沿用原有互斥機制；次要場景視角按鈕至少 44 px。人物標籤移入既有場景標籤裁切層，消除移出畫面時造成的 document 超界。
- 行政入口石材加入細粒／凹凸，依幾何尺寸投影，避免柱與牆紋理比例不同；前庭石板統一為每格 0.5 場景單位。
- 椰林道路加入細粒瀝青、平齊路緣與排水縫；圍籬外補低細節植栽與淡色遠丘。外側草地採烘焙色圖和共享柔邊 alphaMap，避免 Three.js r128 共用 UV 轉換導致遮罩錯誤。沒有新增商家、街名或聲稱現地測量的城市模型。
- 照片校門改為單一右側高塔／金球，內外分面文字、藍黃波紋、塔底實際開口；左側低柱保留既有邊界。警衛室米白／淺藍、紅雙坡瓦頂、窗門、暗色 LED 及遮簷。另提供「校門近景」工具視角便於對照。
- 移除 outdoor-world 重複舊門塔碰撞；實際塔腳與過樑保留 perimeter 語意。校門中央、椰林及行政區既有通行軸不變。

## 範圍限制

照片校正的是可辨認的外觀，尺寸與相對比例仍為示意；校外樹林和山稜為環境佈景，並非完整可漫遊的街區復原。警衛室 LED 保留暗色牌，未臆造照片無法讀取的訊息。
