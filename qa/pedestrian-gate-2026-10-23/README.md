# 警衛室旁學生行人入口

依使用者照片與現場功能確認：寬門為汽機車出入口，門塔與值勤窗之間的小門為學生主要步行入口。

- 補建獨立金屬格柵小門，門片開啟靠警衛室側；警衛室左側留連續穿廊，既有校內白門仍為房門。
- 共用步行起點移至小門外，圖形路網與動態帶路先經小門再入校。
- 選校門行人入口或校外椰林時，排除強制入校，不會先入校再折返。
- 人物出生與步行避開小門通道；文字起點及第一步同步標示小門與車道功能。
- 正式與提案副本同步，原網址與其餘建物功能保留；尺寸仍依照片推估。

2026-10-24 接續完成：獨立審查確認回程例外修正無阻擋發布問題；585 條完整路線稽核全通過，建置成功。最終聚焦測試及公開驗證記錄保存在本目錄。
