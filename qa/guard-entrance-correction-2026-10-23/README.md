# 警衛室入口照片校正（2026-10-23）

依使用者提供的 145159／145223／145245／145326 四張照片核對內外立面，非現地測量。

- 門塔底部改為側向 X 開口，校名面與對聯面落地；周界右端接至塔的校外角，保留側洞通行。
- 警衛室向校內退縮、屋身貼齊塔側；紅瓦屋脊沿屋身長向。
- 校外右端改高窗臺小窗，值勤窗退縮於雨遮下，補上桌面與短欄杆。
- 校內視角順序為公告欄、白門、窗戶、門塔。
- guard 導航終點移到校內白門前，移除後載入程式將終點覆寫回舊位置的特例。
- 新增「警衛室校內側」檢視入口。正式與 proposal 來源同步。

驗證：照片契約、真正碰撞馬達側洞穿越、校門到新門前帶路共 8 項通過；獨立程式審查無阻擋問題；建置成功。完整路線與公開部署結果見本目錄證據。

公開手機回歸另發現示意人物原站位佔用新門前區域，造成最後一段暫停。新增以 guard 導航終點為準的門前淨空區，人物出生與行走均避開；回歸測試先重現 2 人佔用，修正後 26 項師生互動測試全通過，獨立審查無阻擋問題。
