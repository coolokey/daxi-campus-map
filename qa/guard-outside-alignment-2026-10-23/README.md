# 警衛室跨校門內外配置校正

新增照片 205554 配合原四張圖，確認警衛室非整間退到校內。尺寸仍為導覽示意，未經現地測量。

- 主屋從 inward 3.6 移到 1.6；校外右端翼牆伸到 Z 88、屋簷到 Z 88.6，超過塔的校外牆面 Z 87.2。
- 校內白門與門前導航點一起移動，門前人物避讓以導航節點動態計算。
- 值勤窗退縮，桌面縮窄靠右，保留門塔側洞到前廊的通行淨空。
- 右圍牆從門塔旁移接警衛室右外角；末端柱左緣與屋身右緣貼合，沒有周界缺口。
- 新增校門俯視視角，方便檢查塔、屋身、道路與圍牆關係。
- 正式與 proposal 同步；35 項門口與人物測試通過，獨立審查無阻擋問題，建置成功。
