# 七年級新大樓照片外觀調整

照片來源：`校園照片/七年級那邊新大樓的樣貌/767193_0.jpg` 至 `767196_0.jpg`。

沿用 `spatial-plan.js` 的 `new7` 配置、三層樓與教室、樓梯、入口；`campus-data.js` 提供專屬灰色與米白材質，`spatial-world.js` 依既有牆面開窗並將原方柱改成等半徑圓柱，`photo-teaching.js` 補上深棕遮陽格柵、綠色欄杆、白色落水管、淺綠滑門與銀色窗柵。裝飾維持樓層顯示分組與靜態合批。

照片可確認建材、圓柱、欄杆、格柵及平屋簷特徵。照片中的寬階梯、坡道缺乏整棟對位與高程資訊，本次不調整入口高程及平面配置。外觀尺寸仍為導覽示意，非測量重建。

驗證：相關 3 個測試檔、23 項測試通過；空間驗證 109 個目的地可達，無阻塞邊、樓梯或教室入口失敗；桌機 1440×960、手機 390×844 實際瀏覽器檢查，無主控台錯誤與警告、無水平溢出。修改前後截圖及 JSON 報告在本資料夾。正式建置成功，兩個校園導覽入口已同步；本次僅完成本機修改，尚未發布。
