# 3D 校園導覽遊戲版：國中數學密室逃脫／RPG 設計

這個資料夾保留原本 3D 校園導覽的程式與素材，並記錄下一階段「遊戲版」的內容設計。遊戲版可以先沿用現有場景、搜尋、樓層切換、人物漫遊與導覽路徑，再把任務、題目與獎勵疊加在場景上。

## 建議的遊戲流程

1. 玩家選擇「自由導覽」或「數學任務模式」。
2. 從校門口取得第一張任務卡，依線索前往指定處室、樓層或校園地標。
3. 在場景中找到題目物件，完成計算後取得密碼、道具或下一個座標。
4. 以 3～5 個任務組成一章，最後在校慶禮堂或行政處室完成關卡。
5. 顯示解題時間、提示次數、正確率與探索徽章，支援重玩與排行榜（可選）。

## 可融入的國中數學內容

| 主題 | 校園任務例子 | 遊戲互動 |
| --- | --- | --- |
| 一元一次方程式 | 用教室編號、樓層與座位線索解出下一間教室 | 輸入答案解鎖門牌 |
| 二元一次聯立方程式 | 根據兩條路線的距離與步數找出兩個地標座標 | 選擇正確路線 |
| 比與比例 | 按校園平面圖比例尺估算操場或走廊長度 | 拖曳量尺比對實景 |
| 平面幾何 | 計算花圃、司令台、球場的周長與面積 | 尋找指定形狀並輸入面積 |
| 勾股定理 | 估算兩棟建築間的最短直線距離 | 在地圖上選擇斜邊 |
| 坐標與象限 | 依照地圖座標尋找寶箱或 NPC | 移動到指定座標格 |
| 角度與旋轉 | 調整攝影機或箭頭方向，找出正確視線角度 | 旋轉 3D 物件 |
| 統計與平均數 | 分析班級闖關時間或校園調查資料 | 解讀長條圖、平均數與中位數 |
| 機率 | 根據抽卡或寶箱機率選擇風險較低的路徑 | 風險／報酬決策 |
| 數列與規律 | 從校慶 80 週年、樓梯級數或窗格排列找規律 | 輸入下一個數字 |

## 三個可直接製作的關卡

### 關卡一：校門口的座標密令

玩家從校門口取得四個地標的坐標，依象限與距離排序，得到行政大樓的入口密碼。適合練習坐標平面、距離與排序。

### 關卡二：消失的校慶徽章

玩家必須走訪木藝教室、圖書館與操場，利用比例尺、面積與勾股定理，找出徽章藏在哪個地標。適合做成三段式密室逃脫。

### 關卡三：80 秒倒數任務

在煙火秀開始前完成四題：一次方程式、統計圖表、機率選擇與角度旋轉。每答對一題就縮短倒數時間，全部完成後觸發 80 週年煙火彩蛋。

## 技術實作建議

- 將任務資料放在 JSON，欄位包含 `id`、`title`、`location`、`question`、`answer`、`hint`、`reward`。
- 以現有 URL 參數擴充模式，例如 `?mode=game`、`?quest=coordinate-01`。
- 任務狀態先存在瀏覽器 `localStorage`，不需要後端即可支援單機遊玩。
- 答案輸入與提示面板應支援鍵盤、手機觸控及螢幕閱讀器。
- 題目與解答分離，教師可以只更換 JSON 就建立新關卡。
- 保留原本自由探索入口，避免遊戲任務阻礙一般導覽。

## 版本原則

本資料夾是從原始專案複製出的獨立版本。所有遊戲化內容應在新分支中開發；原始 `main` 分支與原本檔案不應直接修改。
